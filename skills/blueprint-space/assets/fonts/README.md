# Bundled fonts

| File | Font | License |
|---|---|---|
| `Inter.woff2` | Inter (variable, Latin subset) | SIL OFL 1.1, see `OFL-Inter.txt` |
| `IBMPlexMono-400.woff2`, `IBMPlexMono-500.woff2` | IBM Plex Mono (Latin subset) | SIL OFL 1.1, see `OFL-IBMPlexMono.txt` |

All three are the Fontsource Latin builds in WOFF2, unchanged otherwise. `space.py` embeds Inter and IBM Plex Mono 400 into each generated page as data URIs. IBM Plex Mono 500 is available for custom styling.
